# Logo do Kaelix OS

O logo é o "Asas": um K com a haste em forma de lâmina e três penas de asa.
Branco (`#F4F6FF`) em fundo índigo quase preto (`#12152B`), com cantos arredondados.
Foi aprovado pelo Kaiky em 10/11/2026.

- `kaelix-logo.svg`: o logo completo, com o fundo. É o que entra no sistema.
- `kaelix-emblema-claro.svg`: só o emblema, em branco, para fundo escuro.
- `kaelix-emblema-escuro.svg`: só o emblema, em índigo, para fundo claro.

No sistema ele fica em `system_files/usr/share/icons/hicolor/scalable/apps/`
como `kaelix-logo.svg` (logo do sistema) e `kaelix-menu.svg` (botão do menu).
